# P versus NP braid: quadratic orientation marker firewall

Date: 2026-08-13
Parent branch: `agent/gpt56-pnp-symmetry-saturation-firewall-20260813-run3`
Status: finite semantic reduction in unrestricted fan-in-two `B_2`; **not** P versus NP.

## Executive result

A different three-layer sparse language collapses most of the intersecting-critical-path ambiguity to **two global negative markers** and isolates the only surviving escape as a quadratic orientation switch.

For `n >= 5`, define

\[
L_n^\diamond=\{x\in\{0,1\}^n: |x|\in\{1,2,n-1\}\}.
\]

This language is in `P` and has

\[
|L_n^\diamond|=\binom n2+2n=O(n^2).
\]

Let `C` be a normalized unrestricted fan-in-two `B_2` circuit with perfect completeness on `L_n^diamond`.

* If an input is isolated, then `C(0^n)=1`.
* If the critical paths of `u,v` intersect and the first intersection gate is **not quadratic** in the Chen--Li--Yang classification, then again `C(0^n)=1`.
* If their first intersection gate is quadratic, then

\[
C(1^n)=1
\quad\text{or}\quad
C(1^n-e_u-e_v)=1.
\]

Hence every circuit in either published critical-path pathology class has a false positive in the fixed set

\[
K_n=\{0^n,1^n\}\cup
\{1^n-e_u-e_v:1\le u<v\le n\},
\]

which has size `binom(n,2)+2`.

The stronger structural statement is the useful one. If `C` avoids both global markers,

\[
C(0^n)=C(1^n)=0,
\]

then **every** intersecting critical-path pair `{u,v}` has a quadratic first-intersection gate and forces the canonical pair witness

\[
\boxed{C(1^n-e_u-e_v)=1.}
\]

Thus, after removing the two-point common core `{0^n,1^n}`, false positives on the weight-`n-2` layer contain the entire critical-path intersection graph, with witness congestion exactly one under the natural edge-to-complement encoding.

Moreover, avoiding both global markers forces the factorization around every such quadratic first-intersection gate to change from `OR` on the all-zero background to `NAND` on the all-one background. For any fixed quadratic raw gate, this transition flips **both input-orientation bits and not the output-orientation bit**. The unresolved circuit problem is therefore no longer an arbitrary one-of-two corner choice: it is a synchronized two-branch orientation switch that must be generated by the low-surplus DAG.

## 1. Finite truth-table classification

Chen--Li--Yang Lemma 4.8 gives, for an intersecting pair `u,v`, the first intersection gate `G`, and every fixing `rho` of the other variables, unary maps

\[
\phi_\rho,\psi_\rho,\chi_\rho:\{0,1\}\to\{0,1\}
\]

such that

\[
C|_\rho(u,v)
=\chi_\rho\bigl(f_G(\phi_\rho(u),\psi_\rho(v))\bigr).
\]

The 16 binary Boolean functions split exactly into:

* 8 quadratic functions
  \[
  ((u\oplus a)\wedge(v\oplus b))\oplus c;
  \]
* 2 nondegenerate linear functions `u xor v xor c`;
* 6 degenerate functions depending on at most one input (including constants).

The following two one-sided closure facts are exhaustive finite truth-table statements.

### OR-positive closure

Let

\[
q(u,v)=\chi(f(\phi(u),\psi(v))).
\]

If `f` is not quadratic and

\[
q(0,1)=q(1,0)=q(1,1)=1,
\]

then

\[
\boxed{q\equiv1.}
\]

Reason: unary substitution/postcomposition of a degenerate gate stays degenerate, while unary substitution/postcomposition of an XOR/XNOR gate can only produce a linear, unary, or constant function. A nonconstant member of those classes has at most two ones. Accepting three corners therefore forces the constant-one function.

### XOR-positive closure through a quadratic gate

If `f` is quadratic and

\[
q(0,1)=q(1,0)=1,
\]

then exhaustive closure gives exactly

\[
q\in\{\operatorname{OR},\operatorname{NAND},1\}.
\]

In particular `q` cannot be XOR, and at least one diagonal corner is accepted.

`verification/pnp-critical-path-slack/check_orientation_marker_firewall.py` exhaustively checks all `16 * 4^3 = 1024` raw-gate/unary-wrapper combinations and the orientation lemma below.

## 2. Circuit embedding

Assume `C` accepts every point of `L_n^diamond`.

### Isolated input

If input `i` has out-degree zero, the circuit is independent of `x_i`. Since `e_i` has weight one and is positive,

\[
C(0^n)=C(e_i)=1.
\]

So every isolated-input circuit hits the common marker `0^n`.

### Intersecting paths: all-zero background

Fix all variables except intersecting `u,v` to zero. The four corners have weights

\[
0,1,1,2,
\]

and therefore `L_n^diamond` has truth table

\[
(0,1,1,1)=\operatorname{OR}.
\]

Perfect completeness forces the three OR-positive corners to be accepted. If the raw first-intersection gate is nonquadratic, the OR-positive closure theorem says the restricted circuit is constant one. Hence

\[
C(0^n)=1.
\]

### Intersecting paths: all-one background

If the first-intersection gate is quadratic, instead fix all variables except `u,v` to one. The four corners have weights

\[
n-2,n-1,n-1,n,
\]

so the target truth table is

\[
(0,1,1,0)=\operatorname{XOR}.
\]

The two off-diagonal corners are positives and must be accepted. The quadratic closure theorem then forces the restriction to be OR, NAND, or constant one. Therefore at least one diagonal negative is accepted:

\[
C(1^n-e_u-e_v)=1
\quad\text{or}\quad
C(1^n)=1.
\]

This proves the fixed marker set `K_n` theorem.

## 3. Avoiding both global markers makes every intersection canonical

Now add

\[
C(0^n)=C(1^n)=0.
\]

For an intersecting pair `u,v`:

1. the all-zero restriction accepts the three OR-positive corners but rejects `00`; therefore it is **exactly OR**;
2. the first intersection gate cannot be nonquadratic, by the OR-positive closure theorem, so it is quadratic;
3. the all-one restriction accepts the two XOR-positive off-diagonal corners and rejects its `11` corner `1^n`;
4. among `{OR,NAND,1}`, the only possibility with `q(11)=0` is **NAND**.

Consequently the all-one `00` corner is accepted:

\[
\boxed{C(1^n-e_u-e_v)=1.}
\]

This conclusion holds separately for every edge of the critical-path intersection graph. Let

\[
\Gamma_C=([n],E_C),\qquad
\{u,v\}\in E_C
\iff
\text{the critical paths of }u,v\text{ intersect}.
\]

Then, whenever the two global markers are rejected,

\[
\boxed{
\{1^n-e_u-e_v:\{u,v\}\in E_C\}
\subseteq C^{-1}(1)\setminus L_n^\diamond.
}
\]

The map `{u,v} -> 1^n-e_u-e_v` is injective. Thus these are `|E_C|` distinct semantic witnesses with congestion one. The remaining quantitative task is now structural: force either global-marker mass, many intersection edges, or a semantic error in the pathology-free defect ledger.

## 4. Exact quadratic orientation jump

A quadratic raw gate has a representation

\[
f(a,b)=((a\oplus\alpha)\wedge(b\oplus\beta))\oplus\gamma.
\]

Any nonconstant unary Boolean map has the unique form `z -> z xor p`. A quadratic output requires all three wrappers to be nonconstant, so write

\[
\phi(u)=u\oplus p,
\qquad
\psi(v)=v\oplus q,
\qquad
\chi(z)=z\oplus r.
\]

After substitution,

\[
q(u,v)=
((u\oplus p\oplus\alpha)\wedge
 (v\oplus q\oplus\beta))
\oplus\gamma\oplus r.
\]

The quadratic normal form is unique. OR has parameters `(1,1,1)` and NAND has `(0,0,1)`. Therefore, if the same raw gate realizes OR with wrapper bits `(p_0,q_0,r_0)` and NAND with `(p_1,q_1,r_1)`, then

\[
\boxed{
 p_1=p_0\oplus1,\qquad
 q_1=q_0\oplus1,\qquad
 r_1=r_0.
}
\]

So a circuit accepting `L_n^diamond` while avoiding both common markers must flip **both** branch orientations between the all-zero and all-one backgrounds at every first intersection.

This is the sharp survivor to charge to the exact low-surplus structure. The flip is not a generic truth-table mismatch; it is a synchronized change on two disjoint critical branches before their first meeting.

## 5. Why the previous Omega(n) face amplifier is not yet a fractional core

The banked face amplifier for the language with positive weights `{2,n-1}` proves `Omega(n)` distinct false positives for an intersecting pair. On each low face indexed by `t`, however, the local theorem alone only says that one endpoint of

\[
\{e_t,\ e_t+e_u+e_v\}
\]

is accepted.

There is a useful proof-method firewall here. Consider the abstract relaxation in which, for every unordered pair `{u,v}`, an adversary may independently choose one endpoint from every such pair over `t notin {u,v}`. Any fractional weighting that hits **every abstract endpoint-choice pattern** must already put total weight at least

\[
\boxed{\binom n2/3}
\]

on the weight-three endpoints alone.

Indeed, hitting every endpoint choice for fixed `{u,v}` implies

\[
\sum_{t\notin\{u,v\}}
\min\bigl(w(e_t),w(e_t+e_u+e_v)\bigr)\ge1.
\]

Dropping the singleton term gives

\[
\sum_{t\notin\{u,v\}}w(e_t+e_u+e_v)\ge1.
\]

Sum over all `binom(n,2)` pairs. Every weight-three point is counted exactly three times, once for each pair inside its support. Hence

\[
3\sum_{|x|=3}w(x)\ge\binom n2.
\]

This does **not** prove that the actual circuit-error hypergraph has large fractional transversal number: actual circuits may realize only a highly correlated subset of the abstract endpoint choices. It proves something more targeted for proof search: `Omega(n)` witness count plus arbitrary binary corner choices cannot by itself yield the constant `tau_f` goal. A successful argument must exploit correlations among the choices.

The orientation-marker theorem supplies exactly such a correlation target. In the new language, all nonquadratic intersections collapse to the common marker `0^n`; and quadratic intersections that avoid both common markers are forced into the rigid OR-to-NAND double-orientation switch.

## 6. Claimant / critic / rebuilder

### Claimant

Use `L_n^diamond`. Put the common markers `0^n,1^n` into the weighted core. Circuits hitting either marker are finished. For the survivors, charge each pair-specific `1^n-e_u-e_v` false positive to the corresponding intersecting critical-path edge, then charge the required double orientation switch to the exact critical-path slack ledger.

### Critic

The current theorem does **not** show that a low-surplus circuit must have many intersection edges. A circuit may reject both global markers and have only a few intersecting pairs, or be pathology-free altogether. The orientation flips occur on baseline critical-path gates as well as on surplus structure; no theorem yet charges them to `(1-o)+delta_1+delta_2`.

A local factorization counterexample also prevents wishful thinking. The same quadratic raw gate can realize OR under one background and NAND under another by flipping both input unary orientations. Thus Lemma 4.8 plus gate classification alone cannot prohibit the exceptional case.

### Rebuilder

The next theorem should track **background-induced orientation bits along critical paths**. For a survivor avoiding `0^n,1^n`, every intersecting pair needs both pre-intersection branch orientations to reverse between the zero and one backgrounds. The high-EV structural question is:

\[
\boxed{
\text{How many synchronized two-branch orientation reversals can a}\
\text{pathology-free / low-surplus }B_2\text{ DAG support per defect unit?}
}
\]

If each exact defect unit can support only `O(log log n)` suitably selected reversals, the requested semantic-witness congestion bound becomes plausible. If baseline equality braids can support `Omega(n)` such reversals at zero defect, that gives the counterexample needed to kill this lane early.

## 7. Barrier and model audit

* **Circuit model.** Every statement is for unrestricted fan-in-two `B_2`. The linear/quadratic/degenerate split enumerates all 16 binary Boolean functions. No DeMorgan, formula, `U_2`, monotone, or algebraic lower bound is imported.
* **Class preservation.** `L_n^diamond` is explicit in `P`, polynomially sparse, and uses no visible or hidden selector. The result therefore removes the previous finite-to-NP selector gap for this local structural test. It does **not** establish hardness at `2n+O(n/log log n)`.
* **Relativization.** The truth-table and critical-path reductions are finite and relativizing. They are structural firewalls, not a relativization escape.
* **Natural proofs.** No large efficiently recognizable truth-table property is constructed. Nothing here claims to bypass Razborov--Rudich.
* **Algebrization.** No arithmetization is used. Recent Missing-String/Range-Avoidance algebrization barriers therefore remain fully applicable to any later attempt to replace this structural argument with Range Avoidance.
* **Boundary discipline.** The Fan--Li--Yang / Chen--Li--Yang counting lemma safely forces a pathology only for gate count `<2n-2`; the equality class remains separately quarantined. The new marker theorem itself has no gate-count hypothesis.
