# P versus NP braid: global coded-marker frontier

Date: 2026-08-13
Branch: `agent/gpt56-pnp-coded-marker-frontier-20260813-run6`
Status: quantitative reduction and uniformity firewall; **not** P versus NP.

## Result

The parent branch proved that a fractional error core of total mass `T(n)` forces some pointwise mixed error at least `1/T(n)`. At the Chen--Li--Yang one-sided magnification interface it is therefore enough that `log T(n) = o(s(n))`, where the gate budget is `2n + O(n s(n) / log^2 n)` and `s(n)` can be `Theta(log^2 n / log log n)`.

A stronger simplification is available. Fix one circuit-independent decoder `D_n : Q_n -> {0,1}^n`. If every permitted deterministic circuit has a false positive `D_n(q)` for some code `q`, then for every distribution over such circuits finite averaging gives pointwise one-sided error at least `1 / |Q_n|`. Injectivity of `D_n` is unnecessary: duplicate codes only duplicate marker mass.

Thus the exact CLY-facing target is

`log |Q_n| = o(s(n))`

plus

`forall C, exists q in Q_n, C(D_n(q)) = 1 != L_n(D_n(q))`.

This is strictly weaker than constant fractional transversal, a constant common core, Omega(n) semantic witnesses, or O(log log n) congestion.

## Bounded-index codes

For `Q_n = [b(n)] x [n]^{r(n)}`, we have `|Q_n| = b(n) n^{r(n)}`. Hence it suffices that

`log b(n) + r(n) log n = o(s(n))`.

At `s(n) = Theta(log^2 n / log log n)`, polynomially many global templates and any

`r(n) = o(log n / log log n)`

are allowed. So the common witness may depend on a slowly growing number of ambient input coordinates; constant-radius markers are not required.

The banked orientation-marker theorem already fits this criterion for the isolated/intersecting-critical-path class: its markers are `0^n`, `1^n`, and `1^n-e_u-e_v`, requiring only a constant template and two indices.

The remaining high-EV target is therefore: for every normalized pathology-free low-surplus B2 circuit, find one false positive whose input is generated by a fixed decoder from `o(log n / log log n)` ambient indices.

## Uniformity firewall

The quantifier order is essential:

`exists D_n, forall C, exists q`

is useful, whereas

`forall C, exists D_C, exists q`

is not. With pairwise-disjoint singleton error sets, every circuit has a one-symbol circuit-dependent decoder naming its own error, while a global hitting catalogue needs one code per singleton. Circuit-internal gate IDs or defect labels do not count unless they determine an ambient input through a decoder fixed before the circuit is known.

## Boundary-radius corollary

Let `B_{n,r}` be the union of the Hamming balls of radius `r` around `0^n` and `1^n`. The crude ordered-index encoding gives

`|B_{n,r}| <= 2 (r+1) n^r`.

Therefore a theorem forcing one error in `B_{n,r(n)}` with `r(n) = o(log n / log log n)` already gives an `exp(o(s))` common catalogue at the high-end frontier.

## Parallel explicit-obstruction lane

If the required positive examples are labeled 1 and the decoded negative markers are labeled 0, the same global catalogue is an explicit obstruction when efficiently generable. Chen--Li--Yang Theorem 4.5 permits obstructions of size `2^{s(n)}` at the `2n + O(n / log log n)` frontier and therefore removes sparse-NP class preservation entirely in that parallel lane. Its conclusion is a deterministic-time circuit lower bound, not the official P-vs-NP theorem, so the two lanes must not be conflated.

## Barrier/model audit

The decoder averaging lemma is finite and relativizing. It does not evade relativization, natural proofs, or algebrization. Downstream structure must remain in unrestricted fan-in-two `B2`. For the sparse-language lane the language must still be one explicit sufficiently sparse NP (or P) language. Most importantly, the decoder must be circuit-independent.
