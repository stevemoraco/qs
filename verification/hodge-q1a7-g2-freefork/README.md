# Hodge q=1,a=7 G2 free-fork finite-core replay

This branch is the public replay target for `stevemoraco/RH-Lean#1220` and `stevemoraco/RH#401`.

The Lean source is intended to be byte-identical to `Millennium/Hodge/R3Q1A7G2FreeForkFiniteCore.lean` at RH-Lean commit `0a6ae7e2b9b40e4662b9530bb9d28f89e6a671f9`.

The replay proves only finite binary-cubic discriminant identities and elementary integer monotonicity. It does not formalize the analytic or algebraic-geometric bridge closing G2 and carries no Hodge conclusion.
