# P versus NP full-cube duality — public finite Lean replay

This directory is a byte-identical public replay of the finite theorem staged
in `stevemoraco/RH-Lean` PR #985.

The theorem proves only the weighted averaging/fractional-transversal arrow.
It does not formalize P versus NP, the parity circuit construction, or the
hypercube random-walk error bound.

Primary model source: Chen--Li--Yang, ECCC TR22-086 rev.1,
https://eccc.weizmann.ac.il/report/2022/086/.
