# NS single-mode finite-spectrum public verifier

This directory contains a byte-identical public replay of the finite Lean algebra in `stevemoraco/RH-Lean`, branch `agent/ns-single-mode-finite-spectrum-finite-20260813-gpt56`.

It verifies only scalar determinant, nilpotence, equal-shell coordinate, and collinearity identities. It does not formalize Fourier decomposition, Leray projection, the linearized Navier–Stokes operator, spectral theory, or any Millennium theorem.
